# factory0-backend

Backend for **factory0.ventures**, built on the
[Factory Zero harness](https://github.com/Factory-Zero/harness) (Rust,
workers-rs). First consumer of the harness; serves `api.factory0.ventures`.

Modules: `factory0-module-email-signup`, `factory0-module-waitlist`.

Bootstrapped from `Factory-Zero/venture-backend-template` once that exists;
see the issues for the order of work.

# Cratefield control plane

The managed service: sign in, pick modules, connect SSO, and get a running
harness venture on Cratefield's Cloudflare. It is itself a harness venture
(`docs/ARCHITECTURE.md`), consuming `Cratefield/harness` as pinned git
dependencies.

- **Epic and children:** issues in this repo, `EPIC #1`.
- **Pricing and the free tier:** #12.
- **The module catalog, published:** [CATALOG.json](CATALOG.json) is the
  curated catalog as a static, versioned document any user or agent can read
  without compiling Rust (#139), generated by
  `cargo run -p cratefield-catalog --example catalog-doc` and checked in CI
  for drift; [catalog.schema.json](catalog.schema.json) documents its shape.
- **Deploy:** [DEPLOY.md](DEPLOY.md) — the workflow that ships
  https://console.cratefield.com, the owner's one-time setup, and rollback.
- **Build the venture to wasm:** `cargo build --target wasm32-unknown-unknown -p cratefield-control-plane`.
